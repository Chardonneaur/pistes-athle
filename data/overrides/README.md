# Contributions communautaires

Un fichier `.json` par site. Le nom du fichier n'a pas d'importance ; c'est le champ
`id` qui relie la contribution à la fiche du ministère.

Les fichiers commençant par `_` sont ignorés par le build (`_exemple.json` sert de modèle).

Voir [CONTRIBUTING.md](../../CONTRIBUTING.md) pour la liste complète des champs.
