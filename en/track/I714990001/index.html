Espace sportif COSEC

Allée du Nord, 71410 Sanvignes-les-Mines · Saône-et-Loire

Espace sportif COSEC is an athletics venue in Sanvignes-les-Mines (Saône-et-Loire), Bourgogne-Franche-Comté, France. It has an cinder / gravel running track. The venue provides changing rooms and showers. The venue is open to the public at set times.
