Où s'entraîner ?

API des pistes d'athlétisme

Vous êtes probablement arrivé ici en appelant /api/tracks?…. Ce site est hébergé sur GitHub Pages, qui sert des fichiers statiques et ignore la chaîne de requête : les paramètres n'ont pas pu être appliqués, et cette page ne prétend pas avoir filtré quoi que ce soit.

Le document de capacités lisible par une machine est ci-dessus dans <script id="capabilities">, et à part : /api/tracks.json.

Trois façons d'interroger l'annuaire

  • /api/index.jsonLes 7 296 installations réduites aux champs filtrables, en un fichier. Téléchargez, filtrez localement : n'importe quelle conjonction, sans serveur.
  • Facettes pré-calculéesUn fichier par critère simple : département, commune, discipline, développement, revêtement, couloirs, accès libre, cellule géographique.
  • /openapi.jsonLe contrat complet, y compris les paramètres de recherche combinables servis par le serveur de recherche lorsqu'il est déployé.

Deux règles à connaître avant d'interpréter une réponse

acces_libre vaut true ou null, jamais false : 5 696 installations sur 7 296 n'ont aucune information d'accès, et un blanc n'est pas un refus.

Les disciplines filtrent sur les agrès déclarés par l'exploitant. Ce qu'un contributeur a déduit d'une orthophoto est rendu à part, dans agres_probables — et saut_indetermine signifie « il y a un sautoir, on ne sait pas lequel ».
